# Personal Portfolio

This repository contains my personal portfolio website created for CS 3365 - Software Engineering at Texas Tech University.

The purpose of this project is to demonstrate the use of Git and GitHub during the software development process, including feature branches, commits, merging, pushing, pulling, and deployment with GitHub Pages.

## Portfolio Sections

- Home
- About Me
- Skills
- Projects
- Contact

## Technologies Used

- HTML
- CSS
- Git
- GitHub
- GitHub Pages

## Projects Featured

- AI vs. Human Text Detector
- SOCOM IGNITE
- Power BI Data Analytics Dashboard
